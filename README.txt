アイカツアンコール カード管理アプリ（機能追加版）

今回の追加機能
- 収集率：図鑑カードのうち、所持または所持枚数1枚以上のカードの割合を表示
- ブランド別検索：カード編集画面でブランド名を入力すると、ブランドフィルターに追加
- 交換リスト：交換予定カードだけを表示するショートカット
- 欲しいカード一覧：欲しいカードだけを表示するショートカット
- カード番号順：昇順・降順で並べ替え（カード名順も追加）
- 画像未登録：画像が登録されていないカードだけを表示

これまでの機能
- Googleログイン、Firestoreへの保存、端末間同期
- カード情報と表面画像を同じFirestoreカードデータに保存
- 既存のカード・画像・所持状況を上書きしない図鑑カード追加
- 1弾通常85種、パラレル12種、プロモーション33種のカード情報

ブランドについて
カード情報マスターにブランド情報が登録されていないカードは、ブランド欄が空欄です。各カードの「編集」からブランド名を入力すると、ブランド別検索で選べるようになります。ブランド名は表記を統一すると検索しやすいです。

GitHubへの反映
1. ZIPを展開します。
2. index.html、app.js、style.css、card-catalog.js、README.txt をリポジトリへアップロードします。
3. Commit changes を押します。
4. Netlifyのデプロイ完了後、アプリを再読み込みします。

注意
- 既存のFirestoreデータは削除されません。
- 画像は利用者自身で選んで登録します。公式画像は同梱していません。
- カード情報は必要に応じてアプリ内で編集してください。
